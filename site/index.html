Что внутри

Отчёты

Посетители, визиты, отказы, время на сайте, сравнение с прошлым периодом, страницы, входы, источники, UTM, устройства, браузеры, ОС.

Цели и воронки

События из кода одной строкой, цели по событию или пути, конверсия по визитам, воронки до 8 шагов внутри визита.

Реалтайм

Кто на сайте прямо сейчас, какие страницы открыты, динамика по минутам за последние полчаса.

Карта кликов

Топ элементов по странице, глубина скролла, тепловая карта прямо поверх вашей страницы без iframe.

Вебвизор

Запись визитов через rrweb. Поля ввода не записываются никогда, текст можно скрыть целиком, записи живут 30 дней.

Приватность по умолчанию

Нет cookie, нет localStorage, IP не сохраняется: посетитель это суточный хеш, который нельзя обратить. Данные удаляются через 24 месяца.

Установка

Нужен VPS с Docker от 2 ГБ памяти и домен с A-записью на него. Сертификат выпускается автоматически.

git clone https://github.com/cutover-team/lupa.git && cd lupa
cp .env.example .env     # домен, почта, пароль ClickHouse
docker compose up -d --build

Дальше одна строка на сайте:

<script async src="https://stats.ваш-домен.ru/lupa.js" data-site="1" data-clicks></script>
